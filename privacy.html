Privacy policy

Whittebz Workspace MCP

Effective date: November 15, 2026 · Operator: Whittebz

This policy covers Whittebz’s personal Google Drive and Google Slides MCP integration and its information website. Google content retrieved by the integration may be processed by the assistant client and AI provider configured for your task.

Data the integration accesses

Depending on the connected server, enabled tools, permissions granted and your instructions, the integration may access:

  • Your Google account email and account identity to identify the connected account.
  • Drive file names, IDs, types, folders, metadata, permissions, comments and file contents needed for the task.
  • Slides presentation contents, including slide text, images or their references, tables, layout information and speaker notes.
  • OAuth access tokens and refresh tokens used to make authorized API requests.

The Drive server currently requests drive, openid and userinfo.email. The Slides server additionally requests presentations. Broad Drive access can permit viewing, editing, sharing and deleting accessible files through enabled tools. The Google consent screen shows the permissions requested by each connection.

How Google data is used

The integration uses Google user data to carry out user-directed tasks: finding and organizing files, retrieving information, creating or editing presentations, exporting content and managing access when requested. Account identity is used to identify the connection; OAuth tokens authenticate API calls.

The integration does not sell Google user data, use it for advertising or credit decisions, or use it to train generalized artificial intelligence or machine-learning models. Google user data is used for the requested assistant features, subject to the Limited Use requirements below.

Assistant and AI provider processing

MCP tool results can include document content, slide text, metadata or images. When your assistant uses these results to answer a question or edit a presentation, relevant information can be transmitted to the AI model provider you have selected, and can be retained in your assistant’s conversation history.

Requests may pass through the gateway or routing service configured in your client. Those services and the selected AI provider handle requests under their own terms, privacy policies, retention rules and account settings. Review these settings, including any data-sharing or model-improvement options, before using private content. Choose processing settings compatible with Google’s Limited Use requirements.

This integration’s OAuth grant does not itself authorize an unrelated use of Google data. Configure and use the assistant only for the Google data processing you intend.

Storage and retention

The MCP server stores OAuth credentials on the machine or environment where it runs, according to that server’s configuration. Exported or downloaded files, assistant conversation histories and operational logs may also persist in the configured client or server storage. They remain until removed under those settings or deleted by the user.

Google-hosted files remain in Google Drive until changed or deleted through Google or an authorized tool. Disconnecting the integration does not delete those files or remove copies already exported or stored in conversation history. External AI providers apply their own retention and deletion procedures.

The public information website has no document-processing backend, Google account connection, upload form, advertising or analytics scripts. It is hosted by GitHub Pages, which may collect technical request information such as IP addresses under GitHub’s Privacy Statement.

Sharing and disclosure

Google data is communicated to Google APIs and, where needed for a user-directed task, the configured assistant, gateways and AI service providers. A sharing tool may change a Google file’s recipients or access settings when you request that action. Any additional disclosure must be limited to purposes allowed by Google’s API Services User Data Policy, such as security, applicable legal obligations or a user-authorized feature.

Google API Limited Use

Whittebz Workspace MCP’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoke access and delete local data

  • Remove the application’s access in Google Account → Third-party connections to stop future authorized access.
  • Use your MCP server’s logout or disconnect action to remove its stored connection. Token revocation behavior depends on the server.
  • Delete exported files, local credentials, logs or conversation history using the relevant client’s settings. Review AI provider account controls for deletion of data held by that provider.
  • For Google-hosted files and permissions, use Google Drive or Slides to review and delete or adjust them.

Credential handling

OAuth tokens should remain in the MCP server’s credential storage. Do not publish tokens, OAuth client secret files or private document content in this site’s repository or public issue tracker. Protect the machine running the MCP server and review the assistant’s settings for approvals of file changes and sharing.

Contact and changes

Contact the operator through the Whittebz Workspace MCP issue tracker for questions about this integration or this policy. Include only non-sensitive information. This policy will be updated when the integration’s data handling changes, with a revised effective date.
